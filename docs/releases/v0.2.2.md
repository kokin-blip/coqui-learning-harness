# CoquiLearn 0.2.2 — macOS signing correction

This release corrects the invalid app-bundle signature in 0.2.1. Download the **0.2.2 arm64 DMG or Mac ZIP** for Apple Silicon/macOS 26. Replace the previous application after quitting it; existing learning data and account storage stay in their separate application-support directory.

## Corrected packaging

- Apply a complete ad-hoc signature to the application, nested frameworks/helpers and native modules instead of skipping signing.
- Unpack and sign the native OCR executable explicitly.
- Fail the build if the app has no resource seal, a nested signature is invalid, a signed resource is changed, or the archived DMG/ZIP loses signature integrity.
- Require browser-download acceptance evidence before producing release metadata.

## Download and Gatekeeper verification

The exact release DMG was downloaded through Chrome. Its checksum matched the built DMG; quarantine remained on the copied application. Apple’s deep/strict signature check passed, including nested code. The previous missing-resource-seal error is gone.

The user reported that the corrected app opened successfully. Its running version/payload, App Translocation, retained quarantine and enabled Gatekeeper were verified. The exact approval-button sequence was not captured. The app’s saved lesson rendered successfully.

**This remains an ad-hoc-signed, unnotarized preview.** It has no Developer ID certificate or Apple notarization ticket. Gatekeeper’s default assessment still rejects it as unnotarized; it is not represented as automatically trusted. You may need System Settings → Privacy & Security → Open Anyway after trying to open the app. See [Apple’s instructions](https://support.apple.com/en-us/102445). No global Gatekeeper disablement or quarantine removal is part of these instructions.

See the attached signature/Gatekeeper reports and verification document for actual test results and limits. Other subscription providers remain available with live testing deferred as previously requested. This release adds no new platforms or metered service use.

Included: macOS DMG and ZIP, corresponding AGPL source, SHA-256 checksums, installation instructions, build manifest and verification reports. LearnHarness attribution and the pinned 0.4.0 baseline remain intact.
