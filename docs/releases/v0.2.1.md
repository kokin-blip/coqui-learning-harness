# CoquiLearn 0.2.1 — macOS

CoquiLearn's first published macOS build brings local adaptive lessons, deliberate practice, a knowledge map and explicit spaced review to Apple Silicon Macs running macOS 26 or later.

This is an **unsigned development preview**, published as the latest release. It does not include Windows, Linux, Intel Mac or iOS builds.

## Download and install

Download the **arm64 DMG** and drag CoquiLearn into Applications, or use the **arm64 Mac ZIP**. Installation instructions are attached as `INSTALL.md`, with `SHA256SUMS` for the application and corresponding AGPL source archives. Updates use manual application replacement.

In Settings, connect ChatGPT and choose the teaching, background and vision models. One compatible model can fill multiple roles. Subscription failures preserve work and never silently switch to API billing.

## Included

- Diagnostic → dependency plan → teaching, committed questions and answers, numeric confidence, separate thinking channels, practice outcomes and explicit Next.
- Searchable session history, dependency diagrams, source/chain/proposition browsing, graph interaction and provenance.
- ChatGPT, Copilot and Grok subscription connections, external Claude Code, API providers and custom endpoints.
- Previewable text/Markdown/PDF/image imports, research and visual tools, isolated interactive demonstrations, evidence history and FSRS review.
- Restart recovery, transactional persistence, durable background delivery, shared-source Undo, Recently deleted and verified backup/restore.
- Compact Moonforest/Dew glass interface, polished system typography and reduced-motion/transparency support.

## Verification and remaining checks

**1,516 automated tests and 62 packaged acceptance checks passed**, plus three isolated installation/replacement checks. The packaged 1,000-proposition streaming sample recorded no frame intervals above 16.7 ms or long tasks; this is a short scripted benchmark, not a live-provider throughput guarantee.

ChatGPT was live-tested for lessons, practice, extraction, demonstrations, SVG/PDF/research workflows, restart and browser reconnect. Other subscription providers remain available; their live verification is deferred to the user's planned friend testing. External API/search/Deepgram delivery is not claimed verified. Claude Code is not installed or updated by CoquiLearn.

Manual accessibility, microphone, native-lifecycle and clean-Mac checks remain before declaring a full parity release. See the attached verification report, or the [build verification](https://github.com/kokin-blip/coqui-learning-harness/blob/v0.2.1/docs/implementation/verification.md) and [coverage ledger](https://github.com/kokin-blip/coqui-learning-harness/blob/v0.2.1/docs/planning/completion-checklist.json).
