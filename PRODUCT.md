# CoquiLearn

## Platform
Electron desktop application for Apple Silicon macOS 26 first. Local use and unsigned tester distribution.

## Product
Adaptive teaching, deliberate practice, a provenance-aware knowledge graph, and spaced retrieval. The learner owns local data; no CoquiLearn account is required.

## Approved decisions
Reuse the audited LearnHarness 0.4.0 engine and suitable integrations with attribution. Rebuild the interface in React. Subscription-first ChatGPT, Copilot, Grok, and unmodified Claude Code. SQLite, typed private IPC, durable input, review evidence, imports, undo, backup and restore.

## Visual authority
The approved Figma draft and docs/design/ui-direction.md define Moonforest/Dew, original coquí graphics, Mac system typography and fluid glass motion. The user’s latest Codex desktop screenshot overrides the earlier floating shell’s spacing and composition: compact rail and session sidebar, full-width title bar, anchored composer, and a single right inspector. Preserve the Coqui visual world.

## Success
A packaged app supports the full audited macOS baseline plus the approved core upgrades, with each claim backed by tests or an explicitly recorded unverified live-provider result.
